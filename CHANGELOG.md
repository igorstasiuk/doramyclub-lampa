## [0.2.0] — 2026-11-03

### Добавлено
- **Аккаунт doramy.club и синхронизация списков.** В настройках плагина: cookie сессии, «Проверить вход» (показывает логин), переключатель синхронизации, «Синхронизировать сейчас», «Отключить аккаунт».
- Двусторонний синк пяти списков сайта — избранное, «На потом», «Смотрю», «Просмотрено», «Брошено»:
  - любое добавление/удаление дорамы в Lampa уходит на сайт через очередь операций (повтор при сбоях сети, защита от потери при неудачной сессии);
  - списки сайта подтягиваются в Lampa (включая постеры и названия); первая синхронизация объединяет обе стороны, дальше сайт главнее, удаления на сайте применяются;
  - автосинхронизация при запуске не чаще раза в час и из меню «Мои списки».
- Опция «Авто-статус «Смотрю»» при запуске серии.

### Безопасность
- Пароль плагин не принимает и не хранит; e-mail аккаунта не читается и не сохраняется (берётся только логин). Cookie отправляется только на адрес сайта из настроек и не уходит на Kodik.

### Известные ограничения
- Вход по логину и паролю невозможен: слой запросов Lampa не отдаёт `Set-Cookie`, поэтому сессию нужно скопировать из браузера.
- Имена действий (`wfm_add`, `budu_delh`, `viewed_add`, `zakl_add`, `broh_add` и т.д.) взяты из скрипта сайта; на реальном аккаунте синхронизация не проверялась.

## [0.1.0] — 2026-11-03

### Добавлено
- Пункт меню **Doramy.club** и страница-дашборд: «Продолжить просмотр», Новинки, Топ, Сериалы, Фильмы.
- Каталог как на сайте: разделы (новинки, фильмы, сериалы, топ всё время/месяца/года), страны, жанры и подборки, годы. Список берётся из меню сайта (кеш 7 дней), при сбое — встроенный запасной.
- Поиск по сайту (`/?s=`), постраничная загрузка «Загрузить ещё», источник «Doramy.club» в общем поиске Lampa.
- Страница тайтла: постер, рейтинг, страна/год/жанры, статус и число вышедших серий озвучки/субтитров, описание, актёры, канал, студия озвучки, похожие.
- **Озвучки**: основная озвучка и субтитры — вкладки сайта; остальные озвучки и субтитры подгружаются из Kodik одним списком с числом серий («6 из 12 эп.»). У каждой озвучки свой список серий, неозвученные серии помечаются. Дорамы только с субтитрами открываются сразу на субтитрах.
- Получение прямого потока (m3u8) из Kodik без iframe; выбор качества (лучшее/720/480/360), качества доступны и внутри плеера Lampa.
- Серии с прогрессом (`Lampa.Timeline`, синхронизация с CUB), «Продолжить», отметки просмотра долгим нажатием; прогресс общий для всех озвучек.
- Личные списки (избранное, на потом, смотрю, просмотрено, брошено) — локально, ряд «избранное» и «продолжить» на главной Lampa.
- Выбор плеера (встроенный, Android, webOS, VLC, Infuse, IINA, mpv, nPlayer, SenPlayer, копирование ссылки).
- Настройки: плеер, качество, предпочитаемый вариант (озвучка/субтитры), прокси, адрес сайта (зеркало), диагностика.
- Тесты: чистые функции на фрагментах реальной разметки и реальной ссылке Kodik; smoke-тест UI на jsdom.

### Известные ограничения
- Сайт отдаёт JS-проверку браузера (anti-bot). Плагин её **не обходит**: без прокси, который её проходит, каталог не загрузится — это видно в «Диагностике».
- Не проверено на устройстве: нативные запросы Android, реальный фокус пультом, внешние плееры, раскладка.
