# Doramy.club для Lampa

Плагин добавляет в Lampa пункт **Doramy.club**: каталог дорам с сайта [doramy.club](https://doramy.club) с выбором озвучки/субтитров и воспроизведением во встроенном или внешнем плеере. Рассчитан на **Android-приставку и Mac**, управляется пультом. Устроен как плагин [AnimeVost для Lampa](https://github.com/igorstasiuk/animevost-lampa): один файл `doramyclub.js` на ES5, без сборки и зависимостей.

## Возможности

**Каталог**
- Дашборд: новые серии (по вашим спискам), продолжить просмотр, «Популярное сейчас», новинки, топ, сериалы, фильмы.
- **Фильтр как на сайте** (`/navi-cl`): раздел, страна, перевод, студия озвучки, годы, жанры (все/любой), исключение жанров, сортировка по рейтингу, «только вышедшие», «без мини»; последний фильтр запоминается.
- Страны, жанры, годы, каналы, перевод (озвучка/субтитры), лакорны, вэб-дорамы, топы; фильтр страны внутри жанров, годов и новинок.
- **Подборки** (77 обложек), **случайная дорама** с фильтрами, **популярные актёры**, поиск по дорамам и **по актёрам**.
- Страница актёра: фото, дата рождения, рост, зодиак, переключатель «только главные роли».

**Страница тайтла**
- Рейтинг и число оценок, HD-постер, жанры, статус, сколько серий вышло с озвучкой/субтитрами, описание, отзывы (чтение), подборки, ряды «В ролях» и «Похожие».
- **Озвучки и субтитры**: основная озвучка и субтитры — вкладки сайта, остальные подгружаются из Kodik одним списком с числом серий («6 из 12 эп.»); у каждой озвучки свой список серий, неозвученные помечены; дорамы только с субтитрами открываются сразу на них; «Автоперевод» раскрывается в серии.
- **Воспроизведение**: плагин сам получает прямой m3u8 из плеера Kodik; качество 720/480/360 в настройках и в плеере; автопереход на следующую серию; **метка заставки** (долгое OK на серии → «Задать пропуск заставки») — Lampa показывает кнопку «Пропустить».
- Прогресс серий (`Lampa.Timeline`, синхронизация через CUB), отметки «просмотрено» долгим нажатием; прогресс общий для всех озвучек.
- «Карточка Lampa» — точный матч в TMDB (оригинальное название + год) и открытие полной карточки.

**Что нового и расписание**
- **Новые серии**: раз в 45 минут читаются 3 страницы ленты сайта и сравниваются счётчики серий у дорам из «Смотрю», избранного и истории. Ряд на дашборде и на главной Lampa, бейдж «+2 оз.», напоминание при запуске. Во время просмотра не запускается.
- **Расписание** по дням недели из текста сайта («серии выходят по субботам»); строится для дорам из ваших списков со статусом «Выходит».

**Списки и аккаунт**
- Избранное, на потом, смотрю, просмотрено, брошено — локально и с **синхронизацией с аккаунтом сайта** (ниже).
- Ряды на главной Lampa: продолжить просмотр, избранное, смотрю, новые серии.

**Надёжность**
- Очередь запросов к сайту (не больше 2 одновременно, пауза настраивается), офлайн-кеш последних 80 страниц, зеркала сайта (добавляете вы сами), понятные ошибки и диагностика с проверкой селекторов на живых страницах.

## Важно: сайт и доступ к нему

1. **Проверка браузера.** doramy.club отдаёт скриптовую anti-bot проверку (cookie `__js_p_` → `__jhash_` → `__jua_`). Обычный запрос из Lampa получает страницу-заглушку вместо каталога. Плагин такую проверку **не решает и не обходит**: он распознаёт заглушку и показывает понятную ошибку. Рабочие варианты — cookie из вашего браузера (ниже), прокси/шлюз, который проверку проходит, либо договорённость с администрацией сайта.
2. **CORS.** В браузерной Lampa запросы к сайту и `kodikplayer.com` блокируются. На Android Lampa делает нативные запросы без CORS. На Mac нужна Lampa, делающая нативные запросы (десктопное приложение), либо прокси.
3. **Прокси** (настройки плагина): префикс, к которому дописывается полный URL, например `https://my-proxy.example/?url=`. Должен пропускать **POST** на `kodikplayer.com/ftor` и заголовок `Cookie`.

«Настройки → Doramy.club → Диагностика» показывает, что именно недоступно (сайт, Kodik, cookie, селекторы) и что делать.

## Cookie: как получить, вставить и перенести

Cookie нужна для аккаунта (списки) и — если сайт закрыт проверкой браузера — для каталога. Пароль плагин не принимает и не хранит.

1. **Получить.** Войдите на doramy.club в браузере на Mac. DevTools → Network → любой запрос к `doramy.club` → заголовок **Cookie** → скопировать значение (строка длинная — набирать её руками не нужно).
2. **Вставить на Mac.** Настройки → Doramy.club → **«Вставить cookie из буфера обмена»** (ненужные префиксы `Cookie:`, кавычки и переводы строк убираются сами). Затем «Проверить вход» покажет логин.
3. **Перенести на приставку без набора.** На обоих устройствах в настройках включите **«Перенос cookie между устройствами»** — cookie подтянется через аккаунт Lampa (CUB), используется более свежая. Внимание: сессия сайта при этом хранится на серверах CUB в вашем аккаунте; по умолчанию выключено. Выключение стирает её из облака.
4. **Обновлять.** Cookie проверки браузера живут около суток (`max-age=86400`), сессия аккаунта — дольше. Когда сайт снова отдаёт заглушку или сессия истекла, плагин сообщит об этом (синхронизация встаёт на паузу, очередь не теряется); вставьте свежую cookie заново и нажмите «Проверить вход».
5. **User-Agent.** Проверка привязана к User-Agent браузера (`__jua_`). По умолчанию плагин шлёт свой; переключатель «User-Agent из cookie» (выключен) заставляет представляться тем браузером, откуда взята cookie. Включайте только если cookie получены вами из своего браузера; соответствие условиям сайта — на вашей ответственности. Диагностика показывает, совпадает ли UA.

Cookie уходит только на адрес сайта из настроек: не на Kodik и не на зеркала. Плагин не регистрирует ключи в синхронизации Lampa без вашего переключателя.

## Аккаунт и синхронизация списков

Избранное и статусы («На потом», «Смотрю», «Просмотрено», «Брошено») синхронизируются с аккаунтом сайта: добавили дораму в Lampa — она появится на сайте, добавили на сайте — появится в Lampa.

- Любое изменение уходит на сайт через очередь операций (повтор при сбоях сети); состояние подтверждается повторным чтением кнопок на странице тайтла, удаление пробуется двумя вариантами (`*_del`, затем `*_delh`).
- Первая синхронизация объединяет обе стороны (ничего не теряется), дальше сайт главнее: удаление на сайте убирает дораму из Lampa; неотправленные локальные изменения не перетираются.
- Истёкшая сессия или заглушка проверки браузера ставят синк на паузу и не стирают списки.
- **Не синхронизируется:** прогресс серий (сайт его не хранит, он идёт через CUB как у обычных фильмов Lampa), «Мои актёры», оценки и комментарии (запись на сайт из плагина не делается: условия сайта на неофициальных клиентов неясны).

## Подключение плагина

**Настройки → Расширения → Добавить плагин** → ссылка на `doramyclub.js` → перезапустить Lampa. Ссылка должна быть доступна устройству:

- закреплённая версия, обновляется мгновенно: `https://cdn.jsdelivr.net/gh/igorstasiuk/doramyclub-lampa@v0.3.0/doramyclub.js`;
- автообновление в рамках 0.x: `https://cdn.jsdelivr.net/gh/igorstasiuk/doramyclub-lampa@0/doramyclub.js` (кеш CDN до 12 ч);
- локально для разработки: `python3 serve.py`.

**Никогда `@latest` и `@main`:** jsDelivr кеширует их на дни, устройство остаётся на старой версии. Тег `latest` на GitHub подвижный и нужен только для git.

## Как устроено получение видео

Карточка на сайте содержит ссылки Kodik (`kodikplayer.com/seria/<id>/<hash>/720p`). Плагин загружает страницу плеера, берёт из неё подписанные параметры, запрашивает `/ftor` (путь читается из скрипта плеера) и расшифровывает ссылку (буквенный сдвиг + base64). Ссылки живут около часа, кешируются на 10 минут.

## Разработка

```bash
npm install
npm test          # run.js — чистые функции; smoke.js — UI на jsdom с фикстурами (сеть не нужна)
npm run lint
npm run check     # версия в коде = верх CHANGELOG = последний тег = latest
python3 release.py X.Y.Z --dry-run   # выпуск: версия, CHANGELOG, тег vX.Y.Z, latest, push, purge jsDelivr
```

Правила как у AnimeVost-плагина: только ES5 (никаких `=>`, `let`, `const`, шаблонных строк, `includes`, `gap:`), контроллер страницы называется `content`, данные сайта попадают в DOM только через `.text()`. Исследование сайта и план улучшений: [docs/IMPROVEMENTS.md](docs/IMPROVEMENTS.md).

## Не проверено

Тесты работают на **фрагментах реальной разметки** сайта и Kodik (сняты 2026-11-03) и не ходят в сеть: сайт за проверкой браузера.

- Не проверялись на устройстве: нативные запросы Android, реальный путь через прокси, фокус пультом и раскладка на ТВ, внешние плееры.
- Синхронизация списков написана по скрипту сайта (`gid-favorites`) и не проверялась на реальном аккаунте; разметку непустой страницы списка (`/regs-*`) подтвердить не удалось, есть запасной разбор.
- Перенос cookie и истории через CUB (`Storage.sync`) проверен только на заглушке Lampa.
- Не проверялись: воспроизведение тайтлов типа `uv`, смена озвучки у фильмов, «Автоперевод» на реальном тайтле, вызов `segments.skip` в живом плеере Lampa, открытие полной карточки TMDB.
- Расписание строится из свободного текста сайта; формат может меняться.
