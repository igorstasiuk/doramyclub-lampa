# Doramy.club для Lampa

Плагин добавляет в Lampa пункт **Doramy.club**: каталог дорам с сайта [doramy.club](https://doramy.club) с выбором озвучки/субтитров и воспроизведением во встроенном или внешнем плеере. Устроен как плагин [AnimeVost для Lampa](https://github.com/igorstasiuk/animevost-lampa): один файл `doramyclub.js` на ES5, без сборки и зависимостей, управление пультом.

## Возможности

- **Дашборд**: продолжить просмотр, новинки, топ, сериалы, фильмы.
- **Каталог**: разделы, страны, жанры, годы; **поиск**; поиск Lampa тоже ищет по Doramy.club.
- **Страница тайтла**: рейтинг, жанры, статус, сколько серий вышло с озвучкой/субтитрами, описание, актёры/канал/студия (открывают их каталог), похожие.
- **Озвучки и субтитры**:
  - у тайтла есть *основная озвучка* (студия из карточки) и/или *субтитры* — это вкладки сайта;
  - остальные озвучки и субтитры подгружаются из Kodik в тот же список, у каждой своё число серий («6 из 12 эп.»), неозвученные серии помечены;
  - если у дорамы только субтитры — открывается сразу вариант с субтитрами;
  - выбор запоминается для каждой дорамы, прогресс просмотра общий для всех озвучек.
- **Воспроизведение**: плагин получает прямой m3u8 из плеера Kodik (без iframe), качество 720/480/360 выбирается в настройках и в самом плеере; автопереход на следующую серию.
- **Прогресс и отметки**: таймкоды в `Lampa.Timeline` (синхронизация через CUB), долгое нажатие OK на серии — отметки «просмотрено».
- **Мои списки**: избранное, на потом, смотрю, просмотрено, брошено — хранятся локально (у плагина нет аккаунта сайта).
- Ряды «Doramy.club: продолжить просмотр / избранное» на главном экране Lampa.

## Подключение

**Настройки → Расширения → Добавить плагин** → ссылка на `doramyclub.js` → перезапустить Lampa. Ссылку нужно сделать доступной устройству, например через jsDelivr по тегу релиза (`https://cdn.jsdelivr.net/gh/igorstasiuk/doramyclub-lampa@vX.Y.Z/doramyclub.js`) или локально: `python3 serve.py`.

## Важно: сайт и доступ к нему

1. **Проверка браузера.** doramy.club отдаёт скриптовую anti-bot проверку (cookie `__js_p_` → `__jhash_`). Обычный запрос из плагина получает страницу-заглушку вместо каталога. Плагин такую проверку **не решает и не обходит**: он распознаёт заглушку и показывает понятную ошибку. Рабочие варианты — открыть сайт через прокси/шлюз, который эту проверку проходит (ваш собственный), или зеркало без неё: адрес задаётся в настройках.
2. **CORS.** В браузере запросы к сайту и к `kodikplayer.com` блокируются. На Android Lampa делает нативные запросы без CORS; в браузере/ПК нужен прокси.
3. **Прокси** (настройки плагина): префикс, к которому дописывается полный URL, например `https://my-proxy.example/?url=`. Прокси должен пропускать **POST** на `kodikplayer.com/ftor` (получение ссылки на видео).

«Настройки → Doramy.club → Диагностика» показывает, что именно недоступно: сайт, прокси или Kodik.

## Как устроено получение видео

Карточка на сайте содержит ссылки Kodik (`kodikplayer.com/seria/<id>/<hash>/720p`). Плагин загружает страницу плеера, берёт из неё подписанные параметры, запрашивает `/ftor` (путь читается из скрипта плеера) и расшифровывает ссылку (буквенный сдвиг + base64). Ссылки живут около часа, кешируются на 10 минут.

## Разработка

```bash
npm install
npm test        # run.js — чистые функции; smoke.js — UI на jsdom с фикстурами (сеть не нужна)
npm run lint
```

Правила как у AnimeVost-плагина: только ES5 (никаких `=>`, `let`, `const`, шаблонных строк, `includes`, `gap:`), контроллер страницы называется `content`, данные сайта попадают в DOM только через `.text()`.

## Не проверено

Тесты работают на **фрагментах реальной разметки** и не ходят в сеть. Не проверялись на устройстве: нативный запрос Android, реальный путь через прокси, фокус пультом и раскладка на ТВ, внешние плееры, воспроизведение тайтлов типа `uv`, переключение озвучек у фильмов (разметка списка озвучек для `/video/` предполагается такой же, как для сериалов).
